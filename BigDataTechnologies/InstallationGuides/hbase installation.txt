============================================================
STEP 10 — CONFIGURE hbase-site.xml
============================================================

Open:

sudo nano /usr/local/hbase/conf/hbase-site.xml


Replace the complete file with:

<?xml version="1.0"?>

<?xml-stylesheet
type="text/xsl"
href="configuration.xsl"?>

<configuration>

    <!-- HBase data stored in HDFS -->
    <property>
        <name>hbase.rootdir</name>
        <value>hdfs://localhost:9000/hbase</value>
    </property>

    <!-- Distributed mode -->
    <property>
        <name>hbase.cluster.distributed</name>
        <value>true</value>
    </property>

    <!-- ZooKeeper client port -->
    <property>
        <name>hbase.zookeeper.property.clientPort</name>
        <value>2181</value>
    </property>

    <!-- ZooKeeper server -->
    <property>
        <name>hbase.zookeeper.quorum</name>
        <value>localhost</value>
    </property>

</configuration>


Save:

Ctrl + O
Enter
Ctrl + X


IMPORTANT:

The following:

hbase.rootdir

MUST match your Hadoop fs.defaultFS.

Current setup:

Hadoop:
hdfs://localhost:9000

HBase:
hdfs://localhost:9000/hbase

STEP 21 — INSERT DATA
============================================================

Syntax:

put 'students', '1', 'info:age', '22'

put 'students', '1', 'info:course', 'BDA'
