step 15: Configure Hadoop's JAVA_HOME
Now we need to tell Hadoop specifically which Java installation to use.
Open the Hadoop environment configuration file:

nano /usr/local/hadoop/etc/hadoop/hadoop-env.sh

Inside the file, find a line containing:

export JAVA_HOME=

If you find it, set it to:

export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64

If it is commented like this:

# export JAVA_HOME=

change it to:

export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64
Save the file

In nano:

Press Ctrl + O
Press Enter
Press Ctrl + X

Then verify the setting with:

grep JAVA_HOME /usr/local/hadoop/etc/hadoop/hadoop-env.sh

You should see:

export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64

Step 17: Configure hdfs-site.xml

Now we'll configure where Hadoop stores the NameNode metadata and DataNode data blocks.

Open:

nano /usr/local/hadoop/etc/hadoop/hdfs-site.xml

Again, to avoid the previous XML problem, delete all existing contents using Ctrl + K repeatedly.

Then paste exactly:

<?xml version="1.0"?>
<?xml-stylesheet type="text/xsl" href="configuration.xsl"?>

<configuration>

    <property>
        <name>dfs.replication</name>
        <value>1</value>
    </property>

    <property>
        <name>dfs.namenode.name.dir</name>
        <value>file:///home/sari/hadoop_data/hdfs/namenode</value>
    </property>

    <property>
        <name>dfs.datanode.data.dir</name>
        <value>file:///home/sari/hadoop_data/hdfs/datanode</value>
    </property>

</configuration>


//Then verify:

cat /usr/local/hadoop/etc/hadoop/hdfs-site.xml
