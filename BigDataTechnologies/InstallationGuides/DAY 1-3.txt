 4. Step-by-Step Lab Implementation

Step 1: Create Sample Dataset
Create `sales.csv`

>nano sales.csv 

```csv
customer_id,product,amount,city
101,Laptop,800,Bangalore
102,Phone,500,Mumbai
103,Laptop,800,Delhi
104,Tablet,300,Bangalore
105,Phone,500,Mumbai
106,Laptop,800,Bangalore
```

Step 2: Start PySpark

```bash
pyspark
```

Step 3: Load Data (Data Ingestion)

```python
from pyspark.sql import SparkSession
spark = SparkSession.builder.appName("RetailAnalysis").getOrCreate()
data = spark.read.csv("sales.csv", header=True, inferSchema=True)
data.show()
```
// Concept Applied: Big Data Source + Data Repository

Step 4: Data Curation (Cleaning & Structuring)
```python
# Remove null values
clean_data = data.dropna()  # drops null value from our table data and assigns it in clean_data
clean_data.show()  # shows clean data without null values


# Convert column types if needed
clean_data.printSchema()
```
// Concept Applied: Data Curation Services

Step 5: Data Analysis (Business Insight)

#Find Top-Selling Products

```python
from pyspark.sql.functions import sum

result = clean_data.groupBy("product").agg(sum("amount").alias("total_sales"))

result.show()
```

// Output:
Laptop → 2400
Phone → 1000
Tablet → 300

// Concept Applied: Big Data Analytics + Adoption

Step 6: Data Sharing (Output Results)

```python
result.write.csv("output", header=True)
```

// This simulates:

* Sharing processed data across teams

// Concept Applied: Data Sharing & Reuse


Step 7: Metadata Understanding (Meta-Repository Concept)

```python
data.printSchema()
```

// Output:

```
customer_id: integer
product: string
amount: integer
city: string
```

// This is metadata, used in:

* Data catalogs
* Governance systems

Step 8: Open Exit (Data Lifecycle End)

```python
spark.stop()
```

// In real systems:

* Data archived or deleted after use

// Concept Applied: Open Exit
